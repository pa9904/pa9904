Unity와 C#으로 게임 플레이 시스템을 구현하고 있습니다.  
플레이어가 느끼는 조작감과 시스템의 안정성을 함께 고민하며, 구현 → 테스트 → 개선 과정을 반복합니다.

## 사용 기술

`Unity 6` `C#` `Git` `GitHub`

- **게임 플레이** — 이동·조준·사격, 적의 목표 선택과 추적·공격
- **시스템 설계** — ScriptableObject 기반 데이터, 이벤트를 통한 시스템 연결
- **리소스 재사용** — 적·발사체·전투 효과의 오브젝트 풀링
- **검증** — EditMode·PlayMode 테스트, Windows 빌드와 실행 확인

## 만들고 있는 게임

### LAST CIRCUIT — 마지막 회로

**Windows PC · 싱글 플레이 · 2D 탑다운 액션 디펜스**

모든 장치를 켤 전력은 없습니다. 포탑·방어막·감속장 중 두 장치에 전력을 공급하고, 직접 이동하며 사격해 마지막 코어를 지키는 게임입니다.

| 구현 분야 | 주요 내용 |
|---|---|
| 전력 재배분 | 세 가지 장치 조합과 전환 대기시간 |
| 전투와 적 AI | 플레이어 사격, 플레이어 추적형·코어 공격형 적 |
| 풀링과 전투 연출 | 적·발사체 재사용, 피격 섬광과 사망 파편·효과음 |
| 게임 진행 | 웨이브 데이터, 6웨이브 전투, 승리·실패·재시작 |

현재 플레이 테스트와 성능 검증을 진행하며 완성도를 다듬고 있습니다.

## 개발할 때 중요하게 보는 것

- 게임 판정과 시각·음향 연출의 역할을 분리합니다.
- 작은 기능부터 구현하고, 재현 가능한 조건에서 동작을 확인합니다.
- 오류의 원인과 해결 과정을 기록하고, 회귀 테스트로 다시 확인합니다.
- 기능 단위의 변경을 Git으로 관리하며 코드와 문서를 함께 정리합니다.
